Thấy file chứa toàn 0,1 --> nghĩ ngay tới mã nhị phân   
		
Có thể tự code tách 8 ký tự 1 (chuyển thành từng mã nhị phân riêng biệt )   
Hoặc bỏ lên CyberChef (Hiện tại chưa khuyến khích tại nó giới hạn ý tưởng )   
![image](/images/1be931d1ae9c3588baa2d36bd50f0df4.png)



Sau tách chúng ta có thể chuyển nó thành dạng ASCII để xem có đọc được ko
			(Có thể dùng CyberChef để tiện lưu file ASCII lại )  
			--> Khi đó thấy 1 file chuỗi ký tự không thể đọc và còn bị lặp nx  
![image](/images/8a455071f7a23a0398ab6ea5fb5c4f43.png)
