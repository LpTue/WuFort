1 min

Tải bài tập tại đây

Ta tìm thấy file mã

Ta trích xuất file dưới dạng key_file

Theo log thì nó báo quyền truy cập chmod 600 key_file

Theo tìm hiểu thì do wsl ko hỗ trợ chỉnh sửa trực tiếp Ta phải làm theo các bước :

Tạo hoặc chỉnh sửa file wsl.conf:

sudo nano /etc/wsl.conf

Thêm nội dung sau vào file (nếu chưa có):

[automount]
options = "metadata"

Lưu file (nhấn Ctrl+O, Enter, rồi Ctrl+X nếu dùng nano). Khởi động lại WSL bằng cách mở PowerShell hoặc Command Prompt của Windows (không phải terminal Linux) và gõ:

wsl --shutdown

Mở lại terminal Linux (WSL). Bây giờ lệnh chmod 600 key_file trong thư mục /mnt/d/… của bạn sẽ hoạt động.
